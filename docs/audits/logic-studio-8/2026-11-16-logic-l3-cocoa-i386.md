## Limites techniques et prochaine expérience

**Cocoa est chargé en i386, pas encore utilisé.** Le test ne vérifie pas l'enregistrement de toutes les classes Objective-C, ni leurs méthodes/ABI, ni `NSApplication`, `NSWindow`, `NSMenu`, `NSCell`, `NSGraphicsContext`, interface graphique ou dispatch d'événements. Les travaux concurrentiels ABI Cocotron restent indépendants. Aucune instanciation, fenêtre, rendu OpenGL, audio, plug-in, ni exécution de Logic Pro 8.

**Prochain témoin borné** : chercher les classes Objective-C publiques déjà chargées via le runtime `libobjc`, avec négatif volontaire, sans création d'objet ou appel à une méthode. Conserver le runtime B13 et le cache GLU05 intacts, effectuer l'essai dans un nouveau préfixe, et s'arrêter si le prévol échoue.
