## Obstacle suivant et décision

Avant ce lot :

```text
Cannot load libfreetype.so.6 (ELF): libfreetype.so.6: cannot open shared object file: No such file or directory
```

Après mise à disposition privée de FreeType et de ses dépendances :

```text
Cannot load libfontconfig.so.1 (ELF): libfontconfig.so.1: cannot open shared object file: No such file or directory
```

`src/native/CMakeLists.txt` construit séparément `wrap_elf(FreeType libfreetype.so)` et `wrap_elf(fontconfig libfontconfig.so)`. Fontconfig est le **prochain consommateur bloquant**, pas une dépendance DT_NEEDED de FreeType à ajouter silencieusement à sa fermeture. L'hôte dispose seulement de Fontconfig amd64 (`libfontconfig1` 2.15.0-2.3) ; les emplacements ELF32 usuels sont absents. Aucun défaut de code Carbon n'est démontré ici.

**Priorité suivante :** préparer et qualifier séparément Fontconfig ELF32 et sa fermeture dans ce même modèle privé, puis rejouer le témoin Carbon pour établir l'obstacle suivant éventuel. Ne pas extrapoler les erreurs suivantes tant que les initialiseurs n'ont pas été exécutés. La [matrice L1 précédente](2026-11-14-logic-l1.md) reste applicable pour les autres besoins de Logic ; seul son premier manque exécuté est maintenant avancé de FreeType à Fontconfig.

**GO limité** pour les dépendances natives et témoins de couches ; **L2 BLOCKED**. Ni démarrage de Logic ni aptitude à l'utiliser ne sont revendiqués. Le lot s'arrête au périmètre demandé FreeType et ses dépendances ; aucune intervention sur QuickTime, CoreAudio, Cocoa, CarbonCore ou dyld.
