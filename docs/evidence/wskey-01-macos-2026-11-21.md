# WSKEY-01 — valeur de `kWSMethodInvocationResult` mesurée sur macOS (21 novembre 2026)

**OBS sur un vrai macOS (GitHub Actions) : `kWSMethodInvocationResult` vaut
`"/Result"`, soit 7 octets UTF-8 `2f526573756c74`.** C'est une `CFString`
non nulle. La sonde s'y lie fortement via CoreServices.
Préparé avec l'assistance d'un agent IA (Claude Code) pour le mainteneur.

**Obstacle de la priorité courante :** `dyld` échoue sur
`_kWSMethodInvocationResult` (DotMacKit vers CoreServices) avant le point
d'entrée de Logic 8. Ce lot fournit la valeur publique nécessaire pour le
définir. Il n'implémente rien dans D4rling.

## Méthode

La sonde C déclare elle-même `extern const CFStringRef kWSMethodInvocationResult;`
sans inclure d'en-tête WebServicesCore. Elle est liée par
`clang -arch x86_64 -std=c11 -Wall -Wextra -Werror -framework CoreServices`.
Elle vérifie ensuite :
- la non-nullité ;
- `CFGetTypeID == CFStringGetTypeID` ;
- la conversion UTF-8 par `CFStringGetBytes` ;
- l'égalité à `CFSTR("/Result")` par `CFStringCompare` et par `CFEqual` ;
- la différence avec `CFSTR("Result")`.

Deux autres contrôles ne portent que sur le binaire de la sonde, jamais sur un binaire Apple :
- le type de référence, lu par `nm -m` ;
- un contrôle négatif de liaison avec un symbole fictif.

## Limites

- **Portée :** la mesure porte sur macOS 15.7.9 en **x86_64**. Ce n'est ni une
  mesure i386, ni une mesure de l'époque de Logic 8 (Mac OS X 10.5). La
  valeur s'accorde avec l'hypothèse `"/Result"`, mais n'en est pas une preuve
  historique directe.
- **Contenu publié :** aucun en-tête, binaire ou fichier Apple. La seule
  donnée Apple citée est la valeur de la chaîne, lue à l'exécution par une
  API publique.
- **Conservation :** le journal GitHub est conservé 90 jours par défaut ; cet
  extrait en est l'archive publique.
- **Effet de bord :** le push du workflow a aussi lancé « Darling CI », run
  [44920652580](https://github.com/fr4nck/d4rling/actions/runs/44920652580).
  Ce run ne fait pas partie de la preuve.
- **Ce que ce document ne dit pas :** que D4rling définit déjà ce symbole, ni
  que Logic progresse. Voir [WSKEY-02](wskey-02-osservices-2026-11-21.md).
