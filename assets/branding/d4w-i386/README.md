# D4W / i386 — identité visuelle

Le logotype **D4W**, sous-titré **i386**, est destiné au projet
[D4rling](https://github.com/fr4nck/d4rling). Le dessin est volontairement
minimaliste : fond noir, typographie blanche et filet rectangulaire aux angles
arrondis. Aucun effet de lumière, CD, symbole audio ou couleur violette.

## Versions

- **`original`** : référence noir et blanc validée par le responsable le
  **10 novembre 2026**. Les trois fichiers PNG et le fichier ICO sont les
  exports conservés de cette validation.
- **`ivory`** : adaptation demandée le même jour, avec un filet blanc cassé,
  très légèrement jauni (`#F2DEC7`), et les caractères inchangés en blanc.
  Elle reste une variante proposée tant qu'elle n'est pas confirmée à son tour.
- **`original-trace.svg`** : vectorisation simplifiée de l'image approuvée ;
  les tracés peuvent différer de quelques pixels du PNG original.

Chaque version contient des PNG de 32, 256 et 1024 pixels, et un fichier ICO
Windows 32 bits intégrant 16, 24, 32, 48, 64, 128 et 256 pixels. Les images
et l'icône ne constituent **pas** une preuve de compatibilité i386.

Les ressources sont autonomes et réservées à l'identité de D4rling ; aucune
modification du code, du packaging ou des tests n'est effectuée ici.
